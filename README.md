## Site Structure

- `index.html` — Homepage with category grid, quick starts, and popular articles
- `articles/<category>/<slug>.md` — Markdown source files (add/edit content here)
- `articles/<category>/<slug>.html` — Rendered article pages

## Deploy

This site is deployed via [Vercel](https://vercel.com). Every push to `main` auto-deploys to `help.reisearch.com`.

To add or edit articles, update the `.md` files and regenerate the corresponding `.html` pages.
